Finish the combined recovery stage

Use a dedicated Firefox test profile, with all other Firefox windows closed. In that profile's about:config set the Number preference dom.quotaManager.temporaryStorage.fixedLimit to 32768, then restart that profile. Use this exact localhost origin throughout.

Full procedure and recovery decision · Earlier checks

1. Real quota

Run twice. The test retains filler files until a real quota error, tries a growing SQLite COMMIT, then frees space and verifies recovery. It writes at most 48 MiB of filler and fails if it cannot exhaust quota within that limit.

2. Process termination

Run every boundary twice. Prepare creates a database and a downloadable checkpoint. Save that checkpoint before arming. When the status says ARMED, force-quit the test Firefox using macOS Force Quit (⌥⌘Esc); do not quit normally or just close a tab. Reopen the same profile and this page, import the checkpoint if needed, confirm the forced shutdown below, and verify. The page cannot detect how Firefox exited.

After restarting:

To restart an unfinished run, discard its checkpoint and test database below. Completed results are kept. If currently ARMED, reload this page first.
